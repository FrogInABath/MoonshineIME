# MoonshineIME (CAT S22 Flip Edition)

A modified fork of [woheller69/whisperIME](https://github.com/woheller69/whisperIME) tailored specifically for the CAT S22 Flip running Android Go.

This fork replaces the original Whisper TensorFlow Lite inference backend with Sherpa-ONNX Moonshine Tiny (INT8) and heavily refactors the input method service to integrate with the phone's physical hardware and small form-factor display.

---

## Modifications

### 1. Inference Engine: Whisper TFLite → Moonshine Tiny (INT8)
* **Backend:** Replaced the Whisper TFLite runtime with `sherpa-onnx` running the **Moonshine Tiny (INT8 quantized)** model architecture.
* **Architecture:** Targeted and compiled with native libraries for 32-bit ARM (`armeabi-v7a`) to run locally on the Qualcomm Snapdragon 215 chipset.
* **Latency:** Near-instant local transcription without network dependencies or thermal throttling.

### 2. Hardware Push-to-Talk (Orange Side Button)
* **Key Interception:** Listens for OEM keycode `269` (`KEYCODE_PTT`), mapping the physical orange Action button directly to speech recognition.
* **PTT Logic:** Press and hold starts recording; releasing the key immediately halts the recorder, runs Moonshine inference, and commits transcribed text to the active field.
* **Input Target Validation:** Key listening only engages when an editable text connection is active (`EditorInfo.TYPE_MASK_CLASS != TYPE_NULL`) and the IME is visible, preventing unintended background triggers.
* **Accidental Press Filter:** Press events under 300ms are discarded to prevent stray pocket taps from running inference.

### 3. Screen-Optimized UI & Punctuation Bar
* **Compact Toolbar:** The original multi-row layout and oversized central mic button have been replaced with a slim 44dp single-row toolbar designed for the CAT S22's 2.8" (480x640) display.
* **Punctuation Strip:** Direct touch targets for common punctuation: `,`, `.`, `?`, `!`, `'`, along with `⌫` (backspace with repeat hold), `↵` (enter), and `⌨` (switch to standard keyboard).
* **Smart Spacing:** Punctuation buttons automatically strip trailing whitespace generated by the ASR model before committing punctuation, followed by standard spacing.

## Setup & Deployment

### 1. Model Files
The app expects the Moonshine ONNX model files in the application's external files directory:
`/sdcard/Android/data/org.woheller69.whisper/files/`

Required files:
* `preprocess.onnx`
* `encode.int8.onnx`
* `uncached_decode.int8.onnx`
* `cached_decode.int8.onnx`
* `tokens.txt`

Push them to the device via ADB:
```cmd
adb shell mkdir -p /sdcard/Android/data/org.woheller69.whisper/files/
adb push preprocess.onnx /sdcard/Android/data/org.woheller69.whisper/files/
adb push encode.int8.onnx /sdcard/Android/data/org.woheller69.whisper/files/
adb push uncached_decode.int8.onnx /sdcard/Android/data/org.woheller69.whisper/files/
adb push cached_decode.int8.onnx /sdcard/Android/data/org.woheller69.whisper/files/
adb push tokens.txt /sdcard/Android/data/org.woheller69.whisper/files/
